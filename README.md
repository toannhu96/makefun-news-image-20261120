This project renders a 1024x1024 poster that sums up the day's world news. Running `main.ts` copies `entry.png` to `$MAKEFUN_OUTPUT_DIR/entry.png`.

## Usage

- `MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts`
